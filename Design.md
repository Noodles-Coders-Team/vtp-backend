# 1. Problem
This App should help YouTubers with gaming channels to track existing video performace per game, and plan for future video production

# 2. Success Metric
User easily decides on which video production should be next in pipeline

# 3. Piramid
## Must Have (MVP)
* Game table for easy selection of next video production
* Game ranking, with as easy updating as possible
* Easy adding/reviewing of new and potential games
* Authentication with read and write acesses
* DB Backups and Restore points

## Should Have
* Easy game ranking system. Using VidIQ rank and own metrics.
* Game ranking history view
* Easy tags creation for video publication
* Automatic game grab from steam popular section

## Could Have
* Phone interface to work on the go
* Notification of new games to review

## Won’t Have 
* Timeline monitoring

# 4. Core flow
1. Log In
2. Review Games, new entries
3. Select next Game for production based on ranking
4. Mark as nex in Queue
